# Propaid 제품 방향

## 한 문장 정의

Propaid(프로페이드)은 한국 크리에이터·프리랜서·1인 사업자에게 들어오는 협찬·외주 제안을 구조화하고, 계약·작업·입금·비용을 연결해 실제 수익까지 관리하는 서비스다.

브랜드 슬로건은 **“제안부터 입금까지, 놓치지 않게”**다. Due는 납기와 입금 예정일처럼 놓치면 안 되는 조건을, Pick은 AI가 메일에서 중요한 내용을 골라내는 기능을 뜻한다.

## 최우선 문제

복잡한 이메일과 첨부파일에서 다음 항목을 추출한다.

- 거래처와 거래 유형
- 제안 금액
- 작업 범위와 결과물
- 초안 및 게시 납기
- 수정 횟수
- 게시 조건과 2차 활용 조건
- 지급 조건과 입금 예정일
- 해야 할 일
- 누락되었거나 확인해야 할 계약 조건

예를 들어 “8월 20일까지 유튜브 영상 1건과 쇼츠 2건, 초안은 8월 14일, 2차 활용 3개월, 원천세 포함 150만 원, 게시 후 익월 말 지급”이라는 제안은 거래처·금액·결과물·날짜·사용 기간·지급 조건·위험 항목을 가진 구조화 데이터로 변환한다.

## 제품 흐름

```text
협찬·외주 제안
→ 구조화 및 누락 조건 감지
→ 사용자 확인
→ 거래 저장
→ 작업 일정 관리
→ 입금 상태 관리
→ 업무 비용 차감
→ 실제 수익 확인
```

Notion, Google Calendar, Google Sheets는 확인된 데이터를 내보내는 자동화 수단이며 제품의 핵심 데이터 모델을 대신하지 않는다.

## MVP 입력 전략

Gmail 전체 읽기 권한은 사용자 부담과 Google OAuth 검증 범위가 크므로 초기 단계에서 사용하지 않는다.

1. 첫 MVP: 사용자가 필요한 메일 원문을 직접 붙여넣는다.
2. 다음 단계: 사용자별 전용 주소로 선택한 메일만 전달받는다.
3. Resend Inbound 웹훅으로 본문과 첨부파일을 수신한다.

이 방식은 Gmail·네이버·다음·회사 메일에서 공통으로 사용할 수 있고, 서비스가 접근하는 개인정보 범위를 줄인다.

## 차별화 방향

단순히 “AI가 메일을 읽어 Notion에 넣는 서비스”로 머물지 않는다. 핵심 차별점은 한국어 계약·지급 표현과 프리랜서의 전체 수익 흐름이다.

- 원천세 포함/별도와 실수령액 확인
- 익월 말, 검수 후 N일 등 한국어 지급 표현 해석
- 수정 횟수, 2차 활용 기간, 게시 유지 기간 등 누락 조건 감지
- 제안부터 작업·입금까지 상태 추적
- 기존 구독 비용과 업무 경비를 거래 수익에 연결
- 개인에서 소규모 에이전시와 팀으로 확장

## 요금제 가설

### 무료

- 월 5건 분석
- 거래처·금액·납기 추출
- 작업 체크리스트
- 웹 대시보드 저장

### 유료 — 월 7,900원 가설

- 월 100건 또는 사실상 무제한
- PDF·한글·이미지 첨부 분석
- Notion 등록과 Google Calendar 일정 생성
- 입금 예정일 알림
- 누락 계약 조건 감지
- 거래처별 과거 제안 검색

### 프로 — 월 19,000원 가설

- 여러 수신 주소와 팀 공유
- 거래처별 매출 통계
- 세금계산서·입금 상태 관리
- 맞춤형 Notion DB
- CSV·Google Sheets 내보내기

요금과 한도는 검증 전 가설이며 구현 사실로 간주하지 않는다.

## 연동 우선순위

1. Resend Inbound 이메일 수신
2. LLM Structured Output 기반 구조화
3. 첨부 PDF 파싱 및 OCR
4. Notion Public OAuth/API
5. Google Calendar API
6. Google Sheets API
7. 실제 결제 연동

외부 API를 붙이기 전에도 사용자가 결과를 검토하고 거래로 저장하는 핵심 흐름은 완결되어야 한다.
